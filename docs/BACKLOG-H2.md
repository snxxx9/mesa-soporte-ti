## Orden de prioridad

### Alta
Corresponde a todo lo necesario para que el flujo principal funcione: base de datos, registro, listado, responsable, estado, validaciones y pruebas principales.

### Media
Corresponde a filtros, resumen, historial visible, integración final y documentación.

### Baja
Solo se usaría para mejoras visuales o detalles que no afecten el cumplimiento del MVP. Por ahora no agregamos tareas de prioridad baja para no ocupar tiempo en funciones que no son necesarias.

## Criterio para mover tareas

- **Backlog:** tarea definida, pero todavía no corresponde iniciarla.
- **Por hacer:** tarea del período actual y lista para comenzar.
- **En curso:** alguien está trabajando realmente en ella.
- **En revisión/pruebas:** está terminada por su responsable y falta revisar o probar.
- **Hecho:** revisada y aceptada por el equipo.
- **Bloqueado:** no puede continuar por una causa concreta y debe anotarse la acción tomada.

Las estimaciones son una referencia para comparar después el avance planificado con el real.
